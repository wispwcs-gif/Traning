# AntonFit — тренировки

Готовая версия приложения для GitHub Pages.

## Как залить на GitHub

1. Создай новый репозиторий.
2. Загрузи в корень репозитория файлы и папки из этого архива:
   - `index.html`
   - `src/`
   - `styles/`
   - `README.md`
3. В настройках репозитория открой **Settings → Pages**.
4. Включи публикацию из ветки `main`, папка `/root`.
5. Открой выданную GitHub Pages ссылку.

## Медиа

## Где менять упражнения

Все тренировки, фото и видео находятся в:

`src/data.js`

## Где менять внешний базовый путь

Логика обработки медиа находится в:

`src/app.js`

Сейчас в упражнениях стоят полные URL, поэтому базовый путь менять не нужно.
