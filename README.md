# AntonFit — мобильная версия

Мини-приложение для тренировок на чистом HTML/CSS/JS. Подходит для GitHub Pages и работает без сервера.

## Что внутри

- адаптивный интерфейс под телефон;
- домашний экран «Сегодня тренируем»;
- выбор тренировки с отдельным экраном выбранного дня;
- фото + видео в карусели;
- полноэкранный просмотр фото и видео;
- сложность: лёгкий / нормальный / тяжёлый;
- цветовая маркировка сложности;
- прогресс по подходам, а не только по упражнениям;
- пошаговый режим с логикой: сделал подход → отдых → следующий подход;
- закреплённые кнопки внизу пошагового режима на мобильном;
- таймер отдыха с паузой, сбросом и закрытием;
- RU / 中文;
- Антон-mode с шутками и отмазками;
- сохранение прогресса в localStorage.

## Как менять тренировки

Основные данные лежат в `src/data.js`.
Фото и видео можно заменить в папке `assets/`, а пути к ним указать в `src/data.js`.

Редактор из интерфейса убран, чтобы мобильная версия была проще и чище.

## Запуск

Открой `index.html` в браузере или загрузи папку проекта на GitHub Pages.
